# Pawtastic

Адаптивная вёрстка интернет-магазина одежды и товаров для домашних питомцев.
Стек: HTML, SCSS (методология БЭМ), JavaScript без зависимостей.

## Запуск

```bash
npm install
npm run build   # сборка css/style.css и css/style.min.css (с автопрефиксами)
npm run watch   # пересборка SCSS при изменениях
```

Страницу нужно открывать через локальный сервер (Live Server, `npx serve` и т. п.),
а не двойным кликом по файлу: из `file://` браузер блокирует шрифты и SVG-спрайт.

Готовый `css/style.css` лежит в репозитории, поэтому GitHub Pages работает без сборки.
Стили правятся только в `scss/`, а `css/` пересобирается командой `npm run build`.

## Структура

```
index.html
css/        результат сборки: style.css (подключён в index.html), style.min.css;
            source map создаётся командой `npm run build`
scss/       исходники: global/ (база) и blocks/ (по одному файлу на компонент)
js/         компоненты, каждый в отдельном файле
  burger-menu.js        мобильное меню
  form-validation.js    валидация и отправка форм
  placeholder-links.js  ссылки-заглушки href="#" не прокручивают страницу вверх
  current-year.js       год в копирайте
fonts/  images/
```

## Формы

Формы работают в демо-режиме (бэкенда нет). Чтобы отправлять данные, добавьте форме
атрибут `data-endpoint="https://ваш-сервер/api/..."` — тогда данные уйдут через `fetch` (POST).
